# Personal Dictionary｜导师快速阅读

> 建议阅读时间：3–5 分钟。无需安装软件，本文与仓库首页的截图即可了解完整产品。

## 一句话介绍

Personal Dictionary 是一款以**近义表达辨析**为核心的本地桌面词典：用户输入自己真正遇到的词，AI 生成结构化义项、搭配、例句和关系候选，经过校验与人工审阅后写入个人词库，并逐步形成可探索的多关系知识图谱。

## 为什么做

传统背词产品擅长回答“这个词是什么意思”，但不容易回答“几个都能翻译成同一个中文的词，真实使用时究竟应该选哪个”。

例如 `keep`、`maintain`、`preserve` 都可能译为“保持”，但它们适用的对象、语体、搭配和表达目的不同。这种区别直接影响英语写作、翻译、阅读和真实交流。产品因此不把词汇学习停留在中英对应，而是把**词义边界和语境差异**作为学习中心。

![核心表达辨析：比较 keep、maintain 与 preserve](assets/meaning-discrimination.png)

## 产品怎么工作

1. 用户把阅读、课程、写作或交流中遇到的新词输入生成队列。
2. AI 生成义项层次、核心区别、易混点、搭配、例句和关系候选。
3. 本地核心检查数据结构，拒绝重复、缺失或不符合规则的结果。
4. 审阅界面同时展示 AI 结果和原词条，由用户决定新增、保留或覆盖。
5. 确认后的内容写入本地 Markdown 词库，并进入多关系知识图谱。

## 最终得到什么

它不是一部预先固定、与所有人相同的词典。每个人遇到的词和学习路径不同，AI 只围绕用户真正接触的词生成内容，因此词典会逐渐记录个人的外语知识形成过程。

![完整词汇工作台](assets/product-overview.png)

已确认的词通过中英对应、近义、反义、词族、同主题和易混等关系连接。图谱采用局部探索方式，用户可以筛选关系、展开云团、拖动节点并切换中心词。

## AI 如何参与

生成式 AI 同时出现在两个层面：

- **产品能力：** 根据用户输入生成词条和关系候选，但不能直接写入词库。
- **开发协作：** 用于需求推演、原型迭代、代码协作、内容生成与测试排查。

这不是把产品决策交给 AI。问题定义、功能取舍、交互规则、数据安全边界和最终验收由我负责；模型的不确定性则通过“结构校验—人工审阅—快照写入”的流程进行约束。

## 主要工程设计

- **桌面端：** Electron + React + TypeScript + Vite。
- **本地核心：** Python 3.11，统一负责解析、校验、索引、写入、备份与恢复。
- **数据形式：** Markdown 词条与 JSON 关系索引，内容可读、可迁移。
- **AI 适配：** 不同模型服务收敛为统一调用协议，密钥保留在用户本地。
- **可靠性：** AI 不拥有写入权；写入前审阅，修改前快照，失败后可追踪和恢复。
- **当前验证：** 桌面端 46 项自动化测试通过，React / TypeScript / Electron 正式构建通过。
