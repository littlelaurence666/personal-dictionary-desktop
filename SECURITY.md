# Security and privacy

This repository is a product showcase. It intentionally excludes:

- API keys and provider credentials;
- real user vocabulary libraries and personal paths;
- AI prompts, temporary tasks and model outputs tied to users;
- snapshots and backups;
- the complete commercial core implementation.

Please do not report missing source files as a security issue. For an actual security concern involving the distributed application, contact the repository owner privately through GitHub.
