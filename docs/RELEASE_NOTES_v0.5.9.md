# Personal Dictionary v0.5.9

这是包含默认“演示词库”的 Windows 协作测试版本。

- 首次启动自动绑定 102 项演示词库，无需手动选择文件夹。
- 修复 AI 返回同名英文词条时校验失败的问题：同名内容会在校验前合并、去重。
- 修复生成结果进入审阅界面时可能出现空白页的问题。
- 保留词义辨析、多关系知识图谱、后台生成、新旧内容对比和确认后写入的完整流程。
- 包含多套主题、新手指南、学习接入、关系管理和快照恢复界面。

## 下载选择

- `Personal-Dictionary-v0.5.9-Portable.zip`：推荐给协作测试者；解压后运行 `PersonalDictionary.exe`。
- `Personal-Dictionary-v0.5.9-Setup.exe`：标准 Windows 安装版。

## Windows 提示

当前版本尚未购买商业代码签名证书，因此 Windows 可能显示“未知发布者”或 SmartScreen 提示。请只从本仓库的 Release 页面下载。
