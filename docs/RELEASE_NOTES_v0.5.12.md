# Personal Dictionary v0.5.12

本次版本提升了批量生成的容错能力，并去除了英文词条中仅面向六级考试的栏目名称。

## 主要更新

- 单个词条即使在自动重试后仍未通过校验，也不会中断后续词条的生成。
- 生成结束后会分别显示成功项与失败项，失败项可单独重新生成，不会重复处理已经成功的内容。
- 暂停任务后，仍可从真正尚未处理的词条继续，而不是把失败项误算成未处理项。
- 英文词条栏目“六级写作迁移”统一改为“写作示例”，新生成内容与演示词库均已更新。
- 旧词库中的“六级写作迁移”仍可被读取和校验，无需手动批量改名。

## 下载选择

- `Personal-Dictionary-v0.5.12-Portable.zip`：免安装版，解压后运行 `PersonalDictionary.exe`。
- `Personal-Dictionary-v0.5.12-Setup.exe`：Windows 安装版。

两个版本均内置演示词库；首次启动可直接查看词义辨析、关系图谱与生成审阅流程。
