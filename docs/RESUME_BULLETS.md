# 简历描述备选

## 项目名称

Personal Dictionary｜本地优先的 AI 个人词典桌面应用

## 三行版

- 主导规划并借助生成式 AI 协作实现一款 Electron + React + TypeScript + Python 的 Windows 个人词典，以“核心表达辨析”解决近义词在语义、语域、搭配和使用场景上的选择问题。
- 设计按个人学习经历生长的 AI 工作流，将新词处理为结构化义项、辨析内容和多关系图谱；通过“后台生成—结构校验—新旧对比—逐条决策—快照写入”隔离模型不确定性。
- 完成局部知识图谱、多主题、新手引导、备份恢复、学习来源接入框架及安装/免安装交付；桌面端 `46` 项、Python 核心 `111` 项自动化测试通过。

## 面试展开点

1. 为什么把“核心表达辨析”而不是词频记忆设为产品中心。
2. 为什么选择局部图谱而不是全局图谱，以及关系数量增长后的视觉降噪策略。
3. 为什么坚持 Python 是唯一写入者，以及 Electron IPC 的安全边界。
4. 如何把 AI 从“功能按钮”变成可校验、可审阅、可恢复的稳定工作流。
5. 如何把原 Obsidian/Markdown 工具逐步迁移为可交付的 Windows 桌面软件。
6. 如何通过需求拆分、输出约束、持续验收和测试，让生成式 AI 参与真实产品开发而不替代产品判断。

## GitHub 简介

Local-first AI personal dictionary focused on nuanced word choice, review-before-write generation, and interactive multi-relation knowledge graphs.
