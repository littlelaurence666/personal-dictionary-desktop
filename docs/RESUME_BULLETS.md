# 简历描述备选

## 项目名称

Personal Dictionary｜本地优先的 AI 个人词典桌面应用

## 三行版

- 独立规划并实现一款 Electron + React + TypeScript + Python 的 Windows 个人词典，将 Markdown 词库、结构化复习与局部多关系知识图谱整合为桌面产品。
- 设计 Review-first AI 工作流，以“后台生成—结构校验—新旧对比—逐条决策—快照写入”隔离模型不确定性，避免 AI 直接修改用户数据。
- 完成多主题、新手引导、备份恢复、学习来源接入框架及安装/免安装交付；桌面端 43 项自动化测试通过。

## 面试展开点

1. 为什么选择局部图谱而不是全局图谱，以及关系数量增长后的视觉降噪策略。
2. 为什么坚持 Python 是唯一写入者，以及 Electron IPC 的安全边界。
3. 如何把 AI 从“功能按钮”变成可校验、可审阅、可恢复的稳定工作流。
4. 如何将用户反复提出的视觉反馈沉淀为主题变量、统一卡片与交互状态规则。
5. 如何把原 Obsidian/Markdown 工具逐步迁移为可交付的 Windows 桌面软件。

## GitHub 简介

Local-first AI personal dictionary with structured vocabulary review, review-before-write generation, and interactive multi-relation knowledge graphs.
