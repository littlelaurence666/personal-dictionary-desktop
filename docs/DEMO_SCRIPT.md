# 2 分钟项目演示脚本

## 0:00—0:15｜问题与定位

“这是我独立规划并实现的 Personal Dictionary。它不是把 AI 套在单词表上，而是解决三个问题：词汇内容怎样结构化复习、单词关系怎样可视化、AI 生成怎样安全地进入个人词库。”

画面：打开词汇页，展示中文层的高频、阅读、低频和核心辨析。

## 0:15—0:45｜词汇复习

“中文义项下的英文表达按使用场景分层，核心表达会集中比较语义、搭配和例句。双击已经建立链接的词块，可以直接跳到对应英文词条。”

画面：选择“保持；维持”，依次展示四个区域，再双击 `maintain`。

## 0:45—1:10｜关系图谱

“我没有照搬传统双链，而是把一个词周围的多种关系组织为局部云团。用户可以筛选关系、展开词语，再把目标词切换成新的中心。”

画面：从词汇页点击“同主题词”，进入图谱；展开关系并切换中心词。

## 1:10—1:40｜AI 审阅闭环

“AI 只生成候选内容，不直接修改词库。结果先经过结构校验，再与原词条对比，用户逐条选择新增、保留或覆盖，最后确认才写入。”

画面：输入一个演示词，展示后台进度；进入审阅，切换两个结果并展示新旧对比。

## 1:40—2:00｜工程交付

“底层由 Python 统一处理 Markdown、索引、快照和恢复；Electron 负责桌面体验。我还完成了多主题、学习来源接入框架、自动化测试以及 Windows 安装版和免安装版交付。”

画面：快速展示主题、学习接入和备份页，最后回到项目首页。
