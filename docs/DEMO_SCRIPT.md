# 2 分钟项目演示脚本

## 0:00—0:20｜问题与定位

“很多词在中文里看起来意思相同，但放进真实外语语境后，语义、语气和搭配并不一样。传统背词软件告诉我它们‘是什么意思’，却很难告诉我写作和翻译时‘为什么用这个而不用另一个’。Personal Dictionary 就是从这个问题出发的。”

画面：直接打开“保持；维持”的核心表达辨析，展示 `keep / maintain / preserve`。

## 0:20—0:50｜核心词义辨析

“这里不是三个独立的释义，而是在同一张表里比较它们的核心区别、易混点、搭配和例句。词频分层只负责安排复习顺序，真正的学习中心是下面的辨析。”

画面：依次指向三个表达的“核心区别”和“易混点”，再双击已经建立链接的词块进入英文词条。

## 0:50—1:15｜关系图谱

“我没有照搬传统双链，而是把一个词周围的多种关系组织为局部云团。用户可以只看近义词、词族或同主题词，也可以展开关系，再把目标词切换成新的中心。”

画面：进入 `abandon` 图谱，展示全部六类关系；筛选“同主题词”，展开词语并切换中心词。

## 1:15—1:45｜个人化 AI 生成与审阅

“每个人遇到的词不同，所以我让 AI 按个人遇到的词生成义项、辨析和关系候选。AI 不直接修改词库：结果先经过结构校验，再与原词条对比，用户逐条选择新增、保留或覆盖，最后确认才写入。”

画面：输入一个演示词，展示后台进度；进入审阅，切换两个结果并展示新旧对比。

## 1:45—2:00｜项目角色与工程交付

“这个项目由我提出问题、规划产品与交互、确定数据安全边界，并使用生成式 AI 协作完成原型、代码、内容和测试。底层由 Python 统一处理 Markdown、索引、快照和恢复；Electron 负责桌面体验，最终交付了 Windows 安装版和免安装版。”

画面：快速展示设置、学习接入和备份页，最后回到核心辨析界面。
