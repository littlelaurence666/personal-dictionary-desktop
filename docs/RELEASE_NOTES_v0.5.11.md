# Personal Dictionary v0.5.11

这是包含默认“演示词库”的 Windows 协作测试修复版。

## 本次修复

- AI 返回内容未通过质量校验时，不再第一次失败就停止；每个词条最多自动尝试 3 次。
- 第二、三次生成会收到上一轮的具体校验反馈，能够针对漏项、重复词条或格式错误重新生成完整结果。
- 网络或模型调用暂时失败时也会自动重试，但不会把本地技术错误附加到模型提示中。
- 连续 3 次仍未成功时，界面只显示简明提示，不再把内部校验文本直接展示给普通用户。
- 失败的第一个词条也会保留“重新生成”入口；已完成部分仍可预览，剩余词条可以继续生成。
- 保留审阅后写入原则：自动重试只生成候选内容，不会绕过校验或直接修改词库。

## 下载选择

- `Personal-Dictionary-v0.5.11-Portable.zip`：解压后运行 `PersonalDictionary.exe`，适合快速体验和协作测试。
- `Personal-Dictionary-v0.5.11-Setup.exe`：标准 Windows 安装版，支持选择安装目录、开始菜单和桌面快捷方式。

## 验证结果

- Python 本地核心：117 项测试通过，其中自动重试使用模拟模型验证，没有调用真实 AI。
- 桌面端：46 项测试通过，正式构建通过。
- 免安装版：无窗口健康检查退出码为 0；内置演示词库包含 104 个 Markdown 文件。
