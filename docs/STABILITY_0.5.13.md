# v0.5.13 稳定性检查版

本版重点改善异常后的恢复能力，避免一次失败阻断后续学习，也避免未完成操作误写词库。

## 主要改进

- AI 生成：任务目录避免冲突，明确超时与重试，保留校验纠正反馈；单词失败后继续后续任务，失败项可重试。
- 审阅：导入期间防止重复操作，忽略过期预览，导入后刷新正文；保留新旧词条对比与人工确认。
- 词库与设置：原子保存与损坏恢复，演示词库完整初始化；未完成任务时保护词库切换和备份恢复。
- 关系与图谱：保存失败保留选择，防止重复写入；修复异步响应、连线位置与密集节点展开问题。
- 显示与指南：修复双链别名导致的表格错列，空词库指南可继续；改进退出确认与后台异常处理。
- AI 服务配置：避免切换服务商时旧结果覆盖当前状态，支持手动填写模型或接入点 ID。

## 验证范围

Python 回归 127 项、桌面逻辑回归 92 项通过，类型检查与生产构建通过；完成 11 组隔离 Electron 界面场景与打包后台 11 次请求检查。完整 npm 依赖审计为 0 条已知告警。

生成测试使用模拟响应和临时词库，**不代表所有模型厂商已实网验证**。仍需要不同电脑和实际模型服务的试用反馈，不能保证没有其他问题。
