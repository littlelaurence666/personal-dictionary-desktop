# Personal Dictionary v0.5.7

这是面向作品集展示的 Windows 演示版本。

- 内置完整的“演示词库”，首次启动自动绑定，无需手工选择。
- 展示结构化中英文复习、多关系知识图谱和关系筛选。
- 展示 AI 后台生成、结果预览、新旧内容对比和确认后写入的完整流程。
- 包含多套主题、首次使用指南、学习接入和快照恢复界面。

## 下载选择

- `Personal-Dictionary-v0.5.7-Setup.exe`：推荐，Windows 安装版。
- `Personal-Dictionary-v0.5.7-Portable.zip`：解压后直接运行的免安装版。

## Windows 提示

当前作品集版本尚未购买商业代码签名证书，因此 Windows 可能显示“未知发布者”或 SmartScreen 提示。请只从本仓库的 Release 页面下载。
