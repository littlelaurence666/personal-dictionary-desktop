`personal-dictionary-desktop`

## About

Local-first AI personal dictionary with structured review, review-before-write generation, and interactive multi-relation knowledge graphs.

## Topics

`electron` `react` `typescript` `python` `local-first` `knowledge-graph` `ai` `markdown` `desktop-app` `vocabulary-learning`

## 首个 Release 标题

`Personal Dictionary v0.5.7 — Windows Portfolio Demo`

## Release 简介

这是 Personal Dictionary 的 Windows 作品集演示版本，集中展示结构化词汇复习、局部多关系图谱、AI 生成审阅、本地 Markdown 词库、多主题和备份恢复。

建议下载免安装版并解压后运行 `PersonalDictionary.exe`。首次打开会显示新手指南；演示数据仅用于展示产品流程。

## 仓库置顶理由

完整展示了从产品定义、交互迭代、AI 风险控制、本地数据架构，到 Windows 桌面打包交付的端到端能力。
