# Personal Dictionary v0.5.10

这是包含默认“演示词库”的 Windows 协作测试修复版。

- 首次启动自动绑定 102 项演示词库，无需手动选择文件夹。
- 安装器由 Squirrel 更换为 Unicode NSIS，修复演示词库中文文件名导致的安装失败。
- 修复 AI 已生成完整词条、但辨析表漏掉输入词本身时校验失败的问题；程序只使用该词条已有内容补回输入词行。
- 保留严格边界：整张辨析表为空或核心内容不足时仍会拒绝，不会凭空补造辨析结果。
- 保留同名英文词条合并、生成审阅、多关系知识图谱、新旧内容对比和确认后写入的完整流程。

## 下载选择

- `Personal-Dictionary-v0.5.10-Portable.zip`：解压后运行 `PersonalDictionary.exe`，适合快速体验和协作测试。
- `Personal-Dictionary-v0.5.10-Setup.exe`：标准 Windows 安装版，支持选择安装目录、开始菜单和桌面快捷方式。

## 验证结果

- Python 本地核心：115 项测试通过。
- 桌面端：46 项测试通过，正式构建通过。
- 安装版：已在独立目录完成安装、应用健康检查、演示词库检查、真实界面检查和卸载验证。
